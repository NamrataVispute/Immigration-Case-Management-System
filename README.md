# Immigration Case Management Automation

An end-to-end workflow automation system built using **n8n**, **Google Sheets**, **SMTP**, and **REST APIs** to streamline visa and immigration case processing.

## 🚀 Features

* Automated employee visa case intake
* Dynamic lawyer assignment based on visa type
* Document collection and validation workflows
* Automated email notifications and reminders
* Lawyer review and rework handling
* USCIS approval/rejection tracking
* HRIS integration and status updates
* Audit logging and real-time case tracking

## 🛠 Tech Stack

* n8n Workflow Automation
* Google Sheets
* SMTP / Gmail Integration
* REST APIs
* Conditional Logic (IF/Switch Nodes)

## 📌 Workflow Overview

1. New immigration case created
2. Lawyer automatically assigned
3. Employee receives document request
4. Reminder and escalation logic for pending documents
5. Lawyer reviews submitted documents
6. Case filed with USCIS
7. Approval / RFE / Rejection workflows triggered
8. HRIS and audit logs updated automatically

* Reduced manual HR effort by **70%**
* Improved process efficiency and turnaround time
* Eliminated repetitive follow-ups with automation
* Enabled scalable and centralized immigration case management
